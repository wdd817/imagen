# Agent Plugins 1.0.0 schemas

These unmodified JSON schemas were downloaded on 2026-09-07 from the official Agent Plugins site:

- https://agent-plugins.org/schemas/1.0.0/plugin.schema.json
- https://agent-plugins.org/schemas/1.0.0/mcp.schema.json

The Agent Plugins specification is authoritative for semantic and runtime constraints beyond JSON Schema. `scripts/validate-plugin.mjs` checks both schemas offline and checks the imagen package's runtime files and path containment.
